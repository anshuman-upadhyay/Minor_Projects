For Classic NLP 
Follow this pipeline for making projects 
1. Load Data

2. Clean Text
   - regex
   - lowercase
   - tokenization
   - stopwords
   - stemming/lemmatization

3. Split Data

4. Learn Representation
   - TF-IDF
   - Word2Vec
   - FastText
   - BERT embeddings

5. Convert Text -> Vectors

6. Train Model

7. Evaluate
   - accuracy
   - precision
   - recall
   - F1-score

8. Tune Hyperparameters
